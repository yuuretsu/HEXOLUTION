# Hexolution

Симулятор искусственной жизни на гексагональной сетке, где существа эволюционируют через естественный отбор.

## 🌱 О проекте

Hexolution — это песочница для наблюдения за emergence (возникновением) сложного поведения из простых правил. Каждое существо в симуляции обладает собственным геномом, который определяет его стратегию выживания. Никакого заранее запрограммированного интеллекта — только эволюция.

## 🔬 Как это работает

### Существа
Каждый организм — одноклеточное существо с уникальным геномом. Геном представляет собой программу, которая исполняется пошагово и определяет действия существа: движение, добычу энергии, взаимодействие с окружением и другими организмами.

### "Мышление"
Интеллект существ рождается из исполнения их генома как простой вычислительной машины. Команды генома позволяют считывать информацию об окружении, принимать решения на основе внутреннего состояния и выполнять действия. Сложное поведение возникает из комбинации простых инструкций и эволюционного давления.

### Эволюция
Эволюционный процесс основан на трёх принципах:
- **Наследственность**: существа передают свой геном потомкам
- **Изменчивость**: при размножении происходят случайные изменения в геноме
- **Отбор**: выживают и размножаются только те, кто успешно добывает энергию

Со временем популяция адаптируется к условиям среды, вырабатывая эффективные стратегии выживания.

### Жизненный цикл
Существа рождаются, исследуют мир, добывают энергию различными способами, взаимодействуют друг с другом, размножаются и умирают. Баланс между затратами энергии на действия и её получением определяет успех каждого организма.

## 🚀 Запуск

```bash
# Установка зависимостей
npm install

# Запуск симуляции
npm start
```

## ⚙️ Настройка

Параметры симуляции можно настроить через конфигурационный файл:
- Размер мира и начальная популяция
- Параметры энергии и метаболизма
- Частота и сила мутаций
- Визуальные настройки

## 🎯 Что наблюдать

- Возникновение специализированных стратегий (хищники, собиратели, фотосинтетики)
- Формирование паттернов движения и поиска ресурсов
- Адаптацию к изменяющимся условиям среды
- Динамику популяций и экологические циклы
